# CodexSkin Studio V1.3.0

发布日期：2026-10-03（Asia/Tokyo）。这是针对 V1.2.0 的稳定性与体验修复版，提供 Windows x64 桌面安装器。

## 主要变化

- 自定义主题、颜色、字体和背景调节自动保留；刷新与换图不再丢草稿。
- 后台执行耗时操作，并阻止重复应用与并发清除。
- 图片完整解码、原子保存与 SHA-256 校验；坏配置和丢失图片可以重新选图修复。
- 铺满/完整显示的缩放逻辑修正，背景不再改变菜单和弹层定位。
- 真实挂载健康检查、连接超时、异常反馈、跨窗口失败回退。
- 清除改用应用内确认对话框；失败保留图片和恢复信息，支持重试。
- 更严格的目标与进程校验；不再强制终止全部同名客户端进程。
- 恢复完整的 TOML 子表主题，拒绝不完整快照，兼容 V1.2 的有效快照。
- 提升操作文字可读性，修复小窗口导航、开关点击和提示遮挡。
- 正式程序使用 Windows GUI 子系统，避免多余控制台窗口。

## 使用

1. 安装本页提供的 V1.3.0 安装包，运行 CodexSkin Studio。
2. 在“主题工坊”设置颜色与字体，点击应用保存持久主题。
3. 在“图片背景”选图、调节，点击“应用图片背景”。调节会自动记住，但不会自动改动客户端。
4. 若提示重开，请先保存工作并结束任务，再自行确认。自动正常退出不成功时请手动完全退出客户端重试。
5. “移除当前效果”保留图片与参数；“清除图片”删除工具自己的副本，不删除原图。

## 验证与限制

复现过程、自动化范围与明确未验证项见 [QA-1.3.0.md](QA-1.3.0.md)。没有为了测试而关闭用户当前客户端，也没有操作桌面鼠标。

图片背景仍是实验性会话增强，仅支持 Windows 的兼容 `OpenAI.Codex` 桌面包，不承诺普通 ChatGPT、所有客户端版本或所有页面通用。整页刷新、新窗口和退出后需要重新应用。没有实测用户真实客户端的重开链路，也没有自动覆盖安装。

移除背景不关闭本机调试端口；完全退出客户端并正常启动才能关闭。此功能仅建议用于可信设备。安装器未进行商业代码签名，Windows 可能显示未知发布者，请从本仓库下载并核对发布资产中的 SHA-256。
