# CodexSkin Studio 1.1.0 发布与验证记录

发布日期：2026-09-26（Asia/Tokyo）

## 发布结论

V1.1.0 已完成 Windows x64 的可安装版本。本次升级把单套主题工具扩展为个人主题工作台：新增 4 组浅色/深色主题组合，可一次写入两个外观槽位并让 ChatGPT 跟随系统明暗；新增收藏、最近使用、上次选择记忆和本机字体发现，同时继续沿用 V1.0.0 的键级恢复、完整备份与原子写入安全模型。

本次验收没有对用户现有 ChatGPT 配置执行真实主题写入，也没有重启正在运行的 ChatGPT。组合写入、恢复和原子替换均在隔离测试配置中验证；发布程序只做了启动与只读环境检测，启动前后真实 `config.toml` 的 SHA-256 保持一致。

## 1.1.0 新增内容

- 4 组原创昼夜组合，共覆盖现有 8 套浅色/深色主题
- 一键写入浅色与深色槽位，并将外观模式切换为 `system`
- 主题与昼夜组合收藏、收藏筛选、最近使用快捷入口
- 上次选择记忆；偏好仅保存在本机，损坏数据会安全回退
- Windows 字体注册表扫描、跨平台 `fc-list` 回退和安全字体候选列表
- Windows GitHub Actions CI、贡献指南和安全报告策略

## 已知边界

1. 当前安装器未签名，Windows 可能显示“未知发布者”。公开分发二进制前应配置 Authenticode 代码签名。
2. 本机快速应用依赖当前 ChatGPT 桌面端使用的外观配置字段；字段发生变化时，仍可改用官方主题字符串导入。
3. 字体发现只读取系统公开的字体名称，不读取字体文件内容；某些应用私有字体可能不会出现。
4. 图片/视频壁纸、布局重排和图标替换需要注入，不属于本项目的安全默认能力。
5. macOS/Linux 保留发现回退和可移植代码结构，但尚未产出经过签名与验收的二进制。
