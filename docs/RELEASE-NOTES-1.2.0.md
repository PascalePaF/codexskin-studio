# CodexSkin Studio 1.2.0 发布与验证记录

发布日期：2026-09-26（Asia/Tokyo）

## 发布摘要

1.2.0 在 1.1 的官方颜色主题、昼夜组合、字体发现和精确恢复能力上，新增 Windows 桌面端本机图片背景。用户可以选择 PNG、JPEG 或 WebP，在近似 ChatGPT 工作区中实时预览，再调整图片强度、暗色遮罩、模糊、缩放、焦点、面板透明度与作用范围。

颜色与字体继续使用 ChatGPT 桌面端已有的外观配置；图片背景则是明确标注的实验功能，通过仅绑定 `127.0.0.1` 的会话级 CDP 通道生效。它不会修改 `app.asar`、MSIX、代码签名或快捷方式，也不会读取账号和聊天。

## 主要新增

- 本机 PNG、JPEG、WebP 选择与实时背景预览
- 最大 8 MiB、最长边 8192 px、最多 4000 万像素
- 后端真实图片格式、尺寸和 MIME 一致性校验
- 图片强度、遮罩、模糊、缩放、水平/垂直焦点和面板透明度
- “仅内容区”与“整个窗口”两种范围
- 当前主题颜色与图片背景组合应用
- 首次启用前的二次重启确认
- 当前会话无重启恢复与图片副本清除
- 固定受限样式生成、注入健康检查与失败自动回退
- 浏览器演示模式和独立 Chromium CDP 冒烟测试

## 安全边界

- HTTP 和 WebSocket 都必须精确指向同一个 `127.0.0.1` 端口。
- 不接受用户 CSS、JavaScript、HTML、远程图片 URL 或任意文件路径。
- 图片通过浏览器文件选择器读取，Rust 后端重新检测真实格式后才原子保存到应用数据目录。
- 首次应用若 ChatGPT 已运行且没有本机调试端点，后端只返回“需要重开”，不会自行结束进程；用户必须在确认对话框再次点击。
- 移除效果会删除当前页面样式、背景节点和预注册脚本；清除操作只删除 CodexSkin 自己目录中的固定文件名。
- 不安装常驻服务、计划任务或启动项。

## 已知边界

- 图片背景不是 OpenAI 官方公开主题能力，客户端 DOM 或 Electron 启动行为变化后可能需要适配。
- 图片背景只对当前增强会话生效；完全关闭 ChatGPT 后，需要从 CodexSkin Studio 再次启用。
- 当前发布只提供 Windows x64 安装器。
- 安装器没有商业代码签名证书，Windows 可能显示“未知发布者”。请从本仓库 Release 下载并核对 SHA-256。
- 打开新的独立 ChatGPT 窗口后，若它对应新的调试目标，需要回到 CodexSkin Studio 重新应用一次。

## 恢复方式

1. 在“图片背景”页点击“移除当前效果”，立即移除会话级背景。
2. 点击“清除图片”，同时删除 CodexSkin 保存的图片副本和背景参数；原始图片不受影响。
3. 在“备份与恢复”页撤销颜色主题写入，或恢复首次使用前的外观键。
4. 完全退出并正常重开 ChatGPT，也会使会话级背景失效。
