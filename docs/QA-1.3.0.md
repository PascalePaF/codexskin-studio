# V1.3.0 缺陷复现与回归记录

日期：2026-10-03。所有测试均在后台运行，没有控制桌面鼠标，没有退出/重开用户当前的 ChatGPT/Codex，也没有修改用户真实的配置或聊天数据。

## 先复现、再修复

修复前新增的 4 条后端测试全部失败，修复后全部通过：

| 复现的缺陷 | 修复 | 回归证据 |
| --- | --- | --- |
| PNG 只剩头部、像素数据截断，仍能保存 | 保存前完整解码，限制解码内存 | `rejects_truncated_pixels_even_when_dimensions_are_readable` |
| 背景 manifest 损坏后，重新选图也失败 | 允许有效新图修复坏配置 | `permits_replacing_a_corrupt_manifest` |
| 恢复时丢失用 TOML 子表保存的主题/字体 | V2 快照保存完整 TOML Item，兼容旧值格式 | `restores_nested_theme_tables_and_keeps_unrelated_settings` |
| 不完整快照把缺失字段当作“删除” | 先完整校验，在文档副本上恢复；失败不写入 | `rejects_incomplete_snapshot_without_changing_document` |

## 其他已修复问题

- 自定义主题名称、颜色、字体和导入主题不能跨重开保留。
- 刷新背景状态或更换图片覆盖尚未应用的调节参数。
- 反复点击应用、同时清除/更换图片造成异步竞态。
- 同步磁盘、字体扫描和网络连接占用界面线程。
- WebSocket 没有读取截止时间，JavaScript 异常被当作成功。
- CDP 目标为空或只有标题叫 ChatGPT 的普通网页，也可能被识别为可用。
- 状态仅看端口，不检查图片解码、挂载、尺寸和版本。
- 第二个窗口失败时未清理第一个窗口；清理失败却删除恢复信息。
- 首次连接超时没有保存端口，后续重试无法找到已有会话。
- 铺满使用百分比宽度并二次缩放；完整显示仍被缩放。
- 背景脚本改变所有 body 子节点的定位，影响弹层/浮窗。
- 停用背景仍返回 active=true，并可能触发不必要的客户端重开。
- 图片换名保存顺序可能覆盖旧图；改为 SHA-256 文件名、先写新文件再提交 manifest。
- 图片副本丢失或被修改后无法自助恢复；现提供可恢复警告和重新选图/清除入口。
- 强制结束所有 ChatGPT.exe；改为校验安装包路径、正常关闭指定客户端，失败要求手动退出。
- 小窗口的图标导航没有可访问名称，开关被装饰层遮挡，提示遮住底部按钮。
- 正式程序未设置 Windows GUI 子系统，可能出现额外控制台窗口。

## 分层验证，避免误报

1. **前端单元测试**：偏好存储、坏数据容错、颜色/主题导入、背景参数范围。
2. **Rust 测试**：真实临时目录中的 PNG/JPEG/WebP 校验、文件保存/清除、TOML 恢复、真实 loopback HTTP/WebSocket 故障服务器、跨窗口回退和超时。不会重启客户端。
3. **界面流程测试**：无头 Microsoft Edge 加桌面 IPC 合约桩，验证上传、调节、反复应用、重开确认、停用、移除、清除失败重试、主题草稿和小窗口布局。这里的“重开确认”是模拟后端，不代表真实客户端重启验证。
4. **背景渲染测试**：无头 Edge 直接执行发布包内同一份 `src-tauri/src/wallpaper.js`，验证 cover/contain、内容/侧栏范围、重复挂载和清理、SPA 内容替换、弹层定位、损坏图片和解码中取消。页面是兼容结构夹具，不读取用户聊天。
5. **构建检查**：TypeScript/Vite、Rustfmt、Clippy 严格检查、Windows NSIS 安装器构建、版本资源和 SHA-256。

界面完整背景流程每条测试内循环 3 次，渲染的四种适配/范围组合也各循环 3 次。发布前再将整套无头测试重复 3 轮，失败不自动重试掩盖。

最终本地结果：前端单元 16/16；Rust 28/28；无头 22 场景重复 3 轮，66/66。新增恢复流程测试曾因测试脚本使用旧按钮文案而失败，已修正定位后重新完整执行，没有将失败计为通过。

## 尚未验证的边界

- 没有终止正在承载开发会话的真实客户端，没有实测它的完整重开/注入链路。
- 没有自动执行安装器覆盖用户现有安装；构建通过不等于安装、升级、卸载交互均完成验收。
- 图片背景只支持 Windows 上可识别的 `OpenAI.Codex` 桌面包的兼容页面；并非对所有叫 ChatGPT 的桌面应用通用。
- 会话背景在整页重载、新窗口或退出后需要重新应用。不再使用连接已断开的 CDP session 注册来承诺自动恢复。
- “内容与侧栏”不会改变原生标题栏、独立浏览器、菜单或弹窗；客户端升级后可能需要适配。
- 移除图片效果不会关闭调试端口；完全退出并正常启动客户端后，调试端口才会关闭。本机其他进程可能访问该端口，只在可信设备使用。
- 颜色主题和图片背景分开应用：背景按钮不再隐式写入官方配置，避免背景失败却改变了持久主题。颜色/字体请在主题工坊应用。
