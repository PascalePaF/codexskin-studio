# CodexSkin Studio 1.2.0 规划

日期：2026-09-26（Asia/Tokyo）

## 目标

在现有官方颜色主题能力之上，提供 Windows 桌面安装版的本地背景图片增强，同时保持可预览、可撤销、默认不生效和不修改官方安装文件。

## 官方能力边界

OpenAI 官方桌面设置文档公开支持基础模式、强调色、背景色、前景色、UI 字体和代码字体，但没有公开背景图片字段：

- <https://learn.chatgpt.com/docs/reference/settings#appearance>

因此 1.2.0 将能力分为两层：

1. **稳定主题层**：继续通过 ChatGPT/Codex 的外观配置和 `codex-theme-v1:` 字符串管理颜色与字体。
2. **实验背景层**：只在用户明确启用的当前桌面会话中，通过本机回环 CDP 注入受限样式和本地图片。

## 用户故事

- 选择本地 PNG、JPEG 或 WebP 后立即看到接近 ChatGPT 工作区的预览。
- 调整图片透明度、暗色遮罩、模糊、缩放和构图焦点。
- 选择只影响主内容区，或延伸到整个窗口。
- 一键应用当前主题颜色与背景；需要重启 ChatGPT 时先看到明确说明。
- 一键恢复官方界面，不修改 `app.asar`、MSIX、签名、账号或聊天数据。
- 图片只保存在 CodexSkin Studio 的本机应用数据目录，不上传到任何服务器。

## 安全模型

- 仅接受 PNG、JPEG、WebP；最大 8 MiB、最长边 8192 px、最多 4000 万像素。
- 后端重新识别真实图片格式和尺寸，不信任文件名或浏览器 MIME。
- 不接受用户 CSS、JavaScript、HTML、远程 URL 或任意文件路径。
- CDP HTTP 与 WebSocket 必须同时精确指向 `127.0.0.1`，且端口必须与本机启动端口一致。
- 注入内容由程序根据有限数值生成；恢复会移除样式节点、背景节点和预注册脚本。
- ChatGPT 已运行但没有 CDP 时，首次应用返回“需要重启”；只有用户在确认对话框再次点击才会结束并重开 ChatGPT。
- 不安装常驻服务，不修改官方快捷方式；官方应用重启后需要从 CodexSkin Studio 重新启用背景。

## V1.2.0 范围

- 背景素材选择、校验、本地保存与清除
- 工作区实时预览
- 透明度、暗色遮罩、模糊、缩放、位置、适配模式和作用范围
- 会话级 CDP 应用、健康检查和无重启恢复
- 与当前颜色主题组合应用
- 浏览器演示模式
- Windows x64 安装器与 GitHub Release

## 不在本版本范围

- 修改或重打包 ChatGPT/Codex 官方安装文件
- 开机常驻服务、计划任务或无提示自动重启
- 下载网络壁纸、主题市场或云同步
- 执行第三方 CSS/JavaScript
- macOS/Linux 背景注入二进制发布

## 验收标准

- 前端与 Rust 单元测试全部通过，Clippy 零告警。
- 使用独立 Chromium CDP 测试目标验证注入、状态检查与恢复，不中断当前 ChatGPT 开发会话。
- 980×680 最小窗口无横向溢出。
- 仅启动 CodexSkin Studio 不修改 ChatGPT 配置，也不启动 CDP。
- Release 安装器版本、SHA-256、启动行为和签名状态均写入发布记录。
